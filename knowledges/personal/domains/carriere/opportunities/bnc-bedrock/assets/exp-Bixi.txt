Project: AWS Migration & Infrastructure Modernization — BIXI Montréal 
As AWS Solutions Architect, I led the full analysis and design of the cloud migration strategy for BIXI Montréal, under a  mandate covering the migration of operational infrastructure to AWS, alongside a vendor migration (Lyft → Helium).

Analyzed and documented the existing infrastructure: 20 Python scripts on Windows VMs (operational automation), the Panorama application (Vue3 + Express, Docker on-prem), and their dependencies on Lyft APIs, the MySQL Datamart, and 8 external services.
Designed and evaluated 3 AWS migration scenarios (Big Bang, Hybrid + Shadow Mode, Conservative) with cost estimates (AWS Pricing Calculator), risk matrices, per-script effort tables, and alignment with the AWS Well-Architected Framework.
