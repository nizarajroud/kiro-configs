# 10 AWS Cloud Architect – Serverless & Integration Platform

**Projet :** AWS Serverless Integration Platform – Équipe SALSA (Intégration Applicative AWS)

En tant que AWS Cloud Architect au sein de l'équipe d'intégration SALSA chez Beneva, je conçois et maintiens la plateforme serverless d'entreprise qui fournit des blueprints d'infrastructure réutilisables, des pipelines CI/CD et des directives architecturales permettant aux équipes produit de déployer des workloads event-driven sur AWS en respectant les standards organisationnels et les bonnes pratiques de sécurité.

* Conception de modules Terraform partagés réutilisables et de software templates Backstage sur le portail développeur interne, permettant aux équipes produit de provisionner en self-service une infrastructure AWS serverless standardisée avec des garde-fous de conformité et de gouvernance intégrés.
* Ingénierie de workflows réutilisables GitHub Actions pour les pipelines CI/CD serverless, standardisant les processus de build, test et déploiement à travers plusieurs équipes produit et environnements (lab, dev, production).
* Rédaction et maintenance des directives architecturales et standards de développement pour les services AWS serverless (Lambda, API Gateway, Glue, EventBridge, AppSync, S3, CloudFront, SES), assurant la cohérence et l'excellence opérationnelle à travers l'organisation.
* Implémentation de contrôles de gouvernance via Service Control Policies (SCPs), Permission Boundaries et AWS Config rules pour garantir la conformité des déploiements dans un environnement financier réglementé.
* Configuration de VPC Endpoints (PrivateLink) pour l'isolation réseau des services serverless et mise en place de politiques de chiffrement KMS pour la protection des données au repos et en transit.

Environnement technologique :

* Cloud Services : AWS Lambda, API Gateway, S3, Glue, EventBridge, AppSync, SES, CloudFront, Kinesis, IAM, AWS SSO
* Gouvernance & Sécurité : SCPs, Permission Boundaries, AWS Config, KMS, VPC Endpoints (PrivateLink)
* Infrastructure as Code : Terraform (modules partagés)
* CI/CD : GitHub Actions (workflows réutilisables & composite actions), Jenkins, Nexus, HashiCorp Vault
* Developer Platform : Backstage (Developer Portal, Software Templates), Renovate
* Containers & Orchestration : Kubernetes (EKS), Testkube, FluxCD (GitOps)
* Observabilité : Dynatrace, CloudWatch (logging & metrics)
* Langages : TypeScript, Python (Lambda Powertools)

**Méthodologies :** SAFe/Agile (PI Planning)
