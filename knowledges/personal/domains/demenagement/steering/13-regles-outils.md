# Règles d'outils — Déménagement

## Règle : Airtable = source de vérité des tâches, TickTick = rappels uniquement

- Airtable est la source unique et autoritaire pour toutes les tâches actionnables du déménagement. Toute tâche doit exister dans Airtable.
- TickTick sert uniquement de système de rappel/notification à une heure précise. Un rappel TickTick ne constitue PAS une tâche — il pointe vers une tâche Airtable existante.
- Ne jamais créer une tâche uniquement dans TickTick. Toujours créer d'abord dans Airtable, puis optionnellement un rappel TickTick si un déclenchement horaire est nécessaire.
- Quand on demande "est-ce qu'il y a une tâche pour X ?", chercher dans Airtable, pas dans TickTick.
